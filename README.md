A program that attempts to simulate 3D gas particle diffusion. I made the graphics engine for the program using the OpenGL graphics API and the physics engine is also written by me.

See running the "runningTheProgram.txt" for further instructions on running the program.

Report any issues by opening a issue on the github page or emailing me.

CONTROLS:
OPTION | KEY(S)

QUIT : Esc

Rotation Controls : W,A,S,D,E,Q
Translation Controls : I,K,L,J,O,U

Increase Camera rotation speed : C
Decrease Camera rotation speed : V
Increase Camera Translation speed : B
Decrease Camera Translation speed : N
(NOTE: The speeds are capped to a limit)

Reset Camera Settings : R
